# LearnPlus Tutoring

A front-end fake tutoring website designed to help high school students explore academic support options across mathematics, science, English literature, and history.

## Features

- Subject-specific tutoring pages
- Student sign-up and login pages
- Firebase Authentication integration
- Tutoring schedule page
- Responsive website styling

## Built With

- HTML
- CSS
- JavaScript
- Firebase Authentication

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Note

This project was developed as a student software-development project.
